# Yanlo-EpiTombFit 1.3.0

## Зачем

С **AzuExtendedPlayerInventory** (доп. ряд + быстрые слоты Z/X/C + слоты брони/пояса/wishbone/амулета) иногда ломалась могила, если умер **не дома**, а потом вернулся **через портал**:

- могила **сама исчезала**, вещи пропадали;
- или после **E** на могиле лут оказывался **не в тех слотах** (хотбар вместо быстрых/экипа).

Этот патч сохраняет вещи в могиле и возвращает их **на те же слоты**, откуда они были.

## Куда ставить

- **Клиент** — обязательно (r2modman → `BepInEx/plugins/Yanlo-EpiTombFit/`)
- **Dedicated server** — обязательно (хост копирует ту же папку на сервер)

Нужен **AzuExtendedPlayerInventory** на клиенте и на сервере (как и раньше).

## Что не чинит

- **Надетая** броня при смерти остаётся на теле (ванilla) — в могилу не кладётся.
- Смерть **дома** у нас и раньше обычно работала; патч важнее для **далёкой** смерти + портал обратно.
