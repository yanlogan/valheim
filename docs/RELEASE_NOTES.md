# Как писать Release notes (для друзей)

Канон — `cycle-2026-08-18`: GitHub body + Discord paste. Читатель: друг в игре, не хост.

`PENDING.md` можно техничнее. В `release-body` / Discord его **не копировать**.

Два слоя, не один текст:

| | GitHub (`release-body-*.md`) | Discord (`PENDING_DISCORD.md`) |
|---|---|---|
| Старт | «С чего начать»: STACK / HOWTO / cfg (ссылки на GitHub) + zip | ссылка на GitHub Release |
| Мод | «Нужен, если установлен X» + что чинит | одна строка: фикс/что изменилось, **имя мода в конце** |
| Конфиг | куда положить файл + зачем | «добавлен файлик от спама автопинами» |
| Сервер | блок «делать ничего не нужно» | та же новость одной строкой, без «сервер» |

## Discord

Эталон:

```
https://github.com/yanlogan/valheim/releases/tag/cycle-YYYY-MM-DD
- фикс телепорта с базы Yanlo-PortalWardFix
- фикс пропадания экипировки и быстрых слотов после смерти вне базы Yanlo-EpiTombFit
- мельница, прялка и печь теперь тянут ресы при взаимодействии не только из сундуков/инвентаря, но и из ящиков Yanlo-CraftyBoxesDrawerFix
- добавлен файлик от спама автопинами на карте
- увеличено кол-во перерабатываемой руды в плавильне черного металла
```

- Первая строка — URL релиза. Всё остальное друг прочитает там.
- Буллет = новость глазами игрока. Имя мода в конце, если это мод; без имени, если это файлик/сервер.
- «фикс X», не «чинит», не версии, не «нужен если», не клиент/dedicated.
- Предметы и станки как в игре: плавильня чёрного металла, ящики — не Blast Furnace, не ItemDrawers.
- Не дублируй STACK/HOWTO/cfg/zip — это уже на GitHub.

## GitHub

1. Шапка **С чего начать** — три ссылки на GitHub: [STACK](https://github.com/yanlogan/valheim/blob/main/docs/STACK.md), [HOWTO](https://github.com/yanlogan/valheim/blob/main/docs/HOWTO.md), [cfg/](https://github.com/yanlogan/valheim/tree/main/cfg). Не выкидывать.
2. Одна строка zip → `BepInEx/plugins/` (`Yanlo-*`).
3. Мод: **зачем** (`Нужен, если установлен X`) + **что чинит**.
4. Клиентский конфиг — только если другу надо положить файл. Сначала зачем, потом короткий список.
5. Сервер — **«Изменено на сервере (делать ничего не нужно)»**. Без ini и без «перестрой / рестартни».

Не пиши «мод без изменений». Не оставляй `++`.

## Формулировки

| Плохо | GitHub | Discord |
|---|---|---|
| портал «насквозь» | неработающий телепорт с базы | фикс телепорта с базы Yanlo-PortalWardFix |
| друзья / варды включены / после портала | свои сундуки после захода на сервер / возвращения порталом | *(на GitHub; в Discord не дублировать, если уже есть телепорт)* |
| на клиенте вместе с WardIsLove | Нужен, если установлен WardIsLove | *(нет — имя мода в конце строки)* |
| QS (Z/X/C), не должны пропадать | пропадание экипировки и быстрых слотов при смерти вне базы | фикс пропадания экипировки и быстрых слотов после смерти вне базы Yanlo-EpiTombFit |
| AzuEPI + dedicated | AzuExtendedPlayerInventory | *(нет)* |
| ItemDrawers, Shift+E | тянут ресы при взаимодействии не только из сундуков/инвентаря, но и из ящиков | то же + Yanlo-CraftyBoxesDrawerFix в конце |
| yaml + простыня категорий | файлик от спама автопинами + куда класть + что остаётся на карте | добавлен файлик от спама автопинами на карте |
| `[Furnace] maximumOre = 100`, рестарт, перестроить | плавильня чёрного металла до 100, блок «делать ничего не нужно» | увеличено кол-во руды в плавильне черного металла |

Правила:

- Симптом игрока, не имя бага в коде.
- На GitHub — все ситуации, где друг это ловит (заход **и** портал). В Discord — одна главная.
- Имена модов как в r2modman. Станки/лут по-русски.
- Запрещено: dedicated, r2modman, QS, AzuEPI, «насквозь», «не должны», «перезапиши папку», ключи ini.
