# Готовые cfg (профиль хоста)

Кладёшь **целиком** в:

`%AppData%\r2modmanPlus-local\Valheim\profiles\<твой_профиль>\BepInEx\config\`

| Файл | Мод |
|------|-----|
| `goldenrevolver.quick_stack_store.cfg` | QSS |
| `flueno.SmartContainers.cfg` | SmarterContainers |
| `Azumatt.AzuCraftyBoxes.cfg` | AzuCraftyBoxes |
| `valheim_plus.cfg` | ValheimPlus |
| `Azumatt.AzuAntiArthriticCrafting.cfg` | AAA_Crafting (optional) |
| `com.inventoryux.valheim.cfg` | CraftGuard / InventoryUX (optional) |
| `FixItFelix.AutoMapPins.categories.vanilla.yaml` | AutoMapPins (optional) — не в `sync-cfg.ps1`; копируй сам, если ставишь AMP |

Перезапишет **все** настройки этого мода у тебя (включая бинды из файла). Если свои бинды/мелочи надо сохранить — правь только настройки из [STACK → Конфиги](../docs/STACK.md#конфиги).
